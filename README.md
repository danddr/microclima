# microclima

This repo contains an R script for generating high-resolution microclimatic surfaces using the `microclima` and `NicheMapR` packages. The script model fine-scale variations in temperature and other climatic variables by incorporating factors such as radiation, wind speed, altitude, surface albedo, and topographic effects.

The `microclima` package provides powerful tools to simulate the mechanistic processes that drive local climate variability. Key features include:
- Modelling temperature variations based on landscape features, such as topography and vegetation.
- Accounting for coastal influences, cold air drainage, and surface albedo.
- Tools for calculating canopy cover, leaf architecture, and microclimatic effects on wind speed and radiation.
